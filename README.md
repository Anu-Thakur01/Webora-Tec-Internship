# Webora Tec Internship

My work from the Webora Tec internship. Each task lives in its own folder with its own README explaining what was built and what I practised.

## Tasks

| Day | Task | What it is |
|-----|------|------------|
| 1 | [Personal Intro](Day_01_Task_1_Personal_Intro/) | Single-page personal portfolio |
| 2 | [Product Cards](Day_02_Task_2_Product_Cards/) | Responsive flower shop product grid |
| 3 | [Landing Page](Day_03_Task_3_Landing_Page/) | Landing page for a design studio |
| 4 | [Contact Form](Day_04_Task_4_Contact_Form/) | Contact form with JavaScript validation |

## Running any task
Each task is plain HTML, CSS and JavaScript. Open the folder's `index.html` in a browser. No install or build step is needed.

## Shared design
All four tasks use the same visual style:
- Violet, rose and mint accent colours
- Bricolage Grotesque and DM Sans fonts
- Rounded cards and soft shadows
- Responsive layouts and `prefers-reduced-motion` support

## What I learned
- Writing semantic, accessible HTML
- Building layouts with CSS Grid and Flexbox
- Using CSS custom properties for a consistent theme
- Adding hover effects and animations
- Making pages responsive on phones, tablets and desktops
- Validating a form with vanilla JavaScript

## Tech
HTML5, CSS3, JavaScript, Google Fonts, Git and GitHub
