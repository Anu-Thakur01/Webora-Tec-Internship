# Day 1 – Task 1: Personal Introduction Page

A single-page personal portfolio that introduces **Anu Kumari Hajam** – BCA student, web developer and aspiring UI/UX designer from Kathmandu, Nepal.

## What I built
- A sticky, blurred (glass-style) navigation bar with links to About, Skills and Contact
- **Hero** section with a short intro, two call-to-action buttons and a profile photo card with an "AK" initials badge
- **About** section with a short bio, languages, and cards for education and how I work
- **Skills** section grouped into Development, UI/UX design and Tools
- **Contact** section with email, GitHub, LinkedIn and location
- Footer with copyright

## What I practised
- Semantic HTML (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS custom properties (colours, fonts, radius, shadow) for a consistent theme
- CSS Grid and Flexbox layouts
- Glassmorphism (`backdrop-filter: blur`), hover effects, and subtle float/spin animations
- Responsive design with breakpoints at 900px and 640px
- Accessibility basics: alt text, `aria-label`s, and `prefers-reduced-motion` support
